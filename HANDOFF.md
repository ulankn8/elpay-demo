# ЭлPay — как продолжать работу (и здесь, и в облаке)

Кликабельный прототип приложения **ЭлPay** для показа инвестору: коммуналка, садик и школа,
налоги, уведомления об отключениях. Пилот — город Ош. Все данные вымышленные.

## Где что лежит

| Файл | Что это |
|---|---|
| `index.html` | **Само приложение и единственный источник правды.** Один самодостаточный файл (~330 КБ): вся вёрстка, стили, скрипты и словарь переводов внутри. |
| `tools/p*.py` | Скрипты правок, которыми файл менялся. Каждый — питон со строковыми заменами и `assert` на число вхождений. История, а не сборка: заново их гонять не нужно. |
| `README.md` | Короткое описание для внешнего читателя. |

Пуш в `main` автоматически обновляет витрину: **https://ulankn8.github.io/elpay-demo/**
(GitHub Pages, обновляется за 1–2 минуты).

Приватный артефакт для быстрых показов: https://claude.ai/artifact/3Zhmx9DN1ZKdnV9pfBEwip —
публикуется из любой сессии, если передать этот URL и `capabilities: {"downloads": true}`.

## Как править

Файл огромный, но структурный. Правки — только точечными заменами, не переписыванием целиком:

```python
import io
P='index.html'
s=io.open(P,encoding='utf-8').read()
def rep(old,new,cnt=1):
    global s
    n=s.count(old)
    assert n==cnt, f'expected {cnt}, found {n}: {old[:90]!r}'
    s=s.replace(old,new)
# rep("старый кусок","новый кусок")
io.open(P,'w',encoding='utf-8').write(s)
```

Правила, проверенные болью:

1. **Перед серией правок — копия:** `cp index.html /tmp/index.backup.html`.
2. `assert` на число вхождений обязателен. Один раз замена по пустой строке раздула файл до 31 МБ.
3. Никаких срезов `s[s.find(a):s.find(b)]` — если `b` окажется раньше `a`, получится пустая строка и катастрофа. Только явные строки.
4. После правок обязательно проверить синтаксис:
   ```bash
   python3 -c "import io,re;s=io.open('index.html',encoding='utf-8').read();io.open('/tmp/v.js','w',encoding='utf-8').write('\n'.join(re.findall(r'<script>(.*?)</script>',s,re.S)))" && node --check /tmp/v.js
   ```
5. **Кыргызский обязателен для каждой новой строки.** Словарь — объект `const KY={…}` внутри файла:
   ```python
   i=s.find('const KY='); j=s.find(';\n',i)
   KY=json.loads(s[i+len('const KY='):j]); KY.setdefault("Новая строка","Жаңы сап")
   s=s[:i+len('const KY=')]+json.dumps(KY,ensure_ascii=False,separators=(',',':'))+s[j:]
   ```
   Переводятся текстовые узлы целиком, поэтому склейки вида `${a} · ${b}` в словарь не попадают —
   разносите части по отдельным элементам (`<em>`), иначе строка останется русской.

## Устройство приложения (коротко)

- Экраны — `<section class="scr" id="s-…">`, переходы `go(id,dir)`, вкладки `tab(id)`; `TABS=['home','pay','reports','profile']`.
- Клики делегированы: `data-act="имя"` → функция в объекте `ACT` (и `ACT2`, который в него вливается).
- Состояние — `st` (создаётся в `fresh()`), счета считает `bills()`.
- **Объекты** (`st.obj`: Дом, Родители, Квартира…) — с иконкой и цветом; у счёта поле `who` хранит **id объекта**. Группировка везде по объектам.
- На главной и в отчётах — карусель карточек объектов (`#heroes`, `#rep-heroes`, механика в `hInit/hSlide/hLayout`).
- Шторки — `openSheet(title, html, kind)`, поля проверяются через `fErr('#id','текст ошибки')`.
- Демо-код из SMS: **4815**.

## Порядок работы, когда сессии чередуются

Одновременно в двух местах не работаем. Смена заканчивается пушем, начинается — пуллом.

```bash
# начало смены
git pull --rebase
# конец смены
git add -A && git commit -m "что сделано" && git push
```

Витрина обновится сама. Артефакт — по желанию, из той сессии, где есть доступ.

## Что не переезжает в облако

- Локальная память Claude (`~/.claude/projects/…/memory/elpay-prototype.md`) — поэтому важное держим в этом файле.
- Локальный превью-сервер (`preview_start elpay-prototype`, порт 8095) и встроенный браузер: в облаке
  проверить прототип глазами нельзя. Там — правки, сборка и пуш; смотреть — по ссылке Pages со своего телефона или ноутбука.
